DANIEL PORTFOLIO

1. Buka folder ini di editor HP kamu.
2. Jalankan index.html melalui Live Server / preview browser.
3. File utama sudah terhubung ke:
   - assets/intro-photo.png
   - assets/background.mp4
4. Jangan ganti nama file kecuali kamu juga mengganti path di index.html.
5. Untuk isi project, cari bagian <!-- KARYA --> di index.html.
6. Untuk link dukungan, cari id="supportBtn", ganti href="#" dengan link kamu dan hapus aria-disabled="true".

Catatan:
- Video sengaja muted dan tidak memiliki kontrol audio.
- Tampilan awal memakai foto. Video baru diputar setelah tombol Mulai Pengalaman ditekan.
- Website memakai HTML/CSS/JS murni supaya mudah diedit dari HP.
